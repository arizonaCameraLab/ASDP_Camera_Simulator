# ASDP_CoreSimulator

This repository contains the source code for a simulated Core Module 
for the Apache Strap-Down Pilotage program.

## Getting Started

**Required:** The ASDP_CoreSimulator requires the ASDP_Core library to have been
installed before it is built.  This installs by default in a known system location that can
be found automatically.  The library source can be obtained using:
`git clone https://github.com/reliasolve/ASDP_Core`

**Build:** ASDP_CoreSimulator uses CMake to configure the builds (though other build
systems could be used).  On Ubuntu Linux, this can be done as follows

    sudo apt install cmake
    cd; mkdir src; cd src; git clone https://github.com/reliasolve/ASDP_CoreSimulator
    cd; mkdir -p build/ASDP_CoreSimulator; cd build/ASDP_CoreSimulator
    cmake ../../src/ASDP_CoreSimulator
    make

**Run:** The ASDP_CoreSimulator can be run from the build directory using the
following command: `./ASDP_CoreSimulator NICName` where NICName is the DNS name or
dotted decimal network address of the network interface to use for the simulator.
This can be found using the `ifconfig` command on Linux and `ipconfig` on Windows.

**Documentation:** The primary documentation is available in DOxygen, and
is generated by as part of the build process when DOxygen is available.  On Ubuntu
Linux, this can be generated as follows:
* `sudo apt install doxygen`
* When you build using CMake, it will build DOxygen by default.
* Open doc_doxygen/html/index.html with a web browser to view the documentation.

**Test:** CMake includes the concept of test applications. You can run the tests
by running `make test` in the build directory.
